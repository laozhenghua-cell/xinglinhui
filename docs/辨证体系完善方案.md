# 杏林汇 · 辨证体系完善方案(基于弱点实证)

> 版本 v1 · 2026-08-31
> 依据:①35 例复杂医案实测(34 PASS / 0 FAIL / 1 GAP)暴露的具体短板;②此前三视角诚实评估的结论;③评测集 199 样本 301 项检查的同源性局限(成绩证明自洽,不证明准确)。

## 一、弱点全景(每条附证据)

### A. 方法层(最根本)

| # | 弱点 | 证据 | 影响 |
|---|---|---|---|
| A1 | 评测与规则同源,100% 是"自洽"不是"准确" | 评测样本由规则库倒写;缺独立医师标注真值集 | 无法度量真实水平,"世界顶级"无从谈起 |
| A2 | 辨证是关键词打分,不是病机推理 | "病机提要"是结论后贴的解释,非推导路径 | 未见过的症候组合只会给勉强最高分 |
| A3 | 四诊输入靠患者自报,舌脉不可信 | 舌诊拍照无医师标注金标准;脉诊未接入 | 输入质量决定输出上限 |
| A4 | 无反馈闭环 | 疗效与医师纠正没有回流渠道 | 引擎永不从真实结果中变聪明 |

### B. 引擎层(规则与推理)

| # | 弱点 | 证据 | 影响 |
|---|---|---|---|
| B1 | **无方证直接对应层** | 35 医案唯一 GAP:栀子豉汤证;大青龙汤证只能"麻黄汤+提示" | 《伤寒论》"见症即方"的经典辨病方式缺失 |
| B2 | 症状权重均等,无主次 | 主症/兼症只在多问题层面有,单个证内指标词同权 | "但见一症便是"与"不必悉具"无法区分 |
| B3 | 只有正向加分,无排除减分 | 否定词仅"不参与"匹配,不反向扣分 | "无汗"不能排除表虚,"口不渴"不能排除热证 |
| B4 | 舌脉无决定性权重 | "舍症从脉"只有真热假寒/真寒假热 2 条硬编码 | 舌脉与症状冲突时无通用仲裁 |
| B5 | 证型关系是静态配对表 | 合病/传变靠固定映射,无病机链推导 | 变证(已治未效、坏病)无法推演 |
| B6 | 问诊是被动触发 | 鉴别追问 19 题靠词触发,无主动鉴别路径树 | 复杂鉴别(如眩晕之肝阳/痰湿/气血虚)问不到位 |
| B7 | 危急拦截覆盖窄 | 危候主要靠儿科模式,全库红旗未建 | 胸痛+冷汗等危险组合可能漏报 |
| B8 | 特殊人群无修正 | 无孕妇/儿童/老人辨证与用药修正层 | 同证同治,违背"因人制宜" |
| B9 | 证据等级不透明 | 五运六气(干支推算)与舌脉结论同等权重并列 | 对患者有误导风险 |

### C. 方药层(开方深度)

| # | 弱点 | 证据 | 影响 |
|---|---|---|---|
| C1 | 拟方是"挑选"不是"组方" | 优先级选方 + 加减条目拼装 | 君臣佐使结构未入处方笺 |

| C5 | 合方库小 | 11 对经典合方,实测中肝郁脾虚/心肾不交等靠临时补 | 两证并见时的"合治方"覆盖不足 |

### D. 数据层

### E. 工程层

## 二、完善方案(五期)

### P1 方证直接对应层(补《伤寒论》辨病方式)★最高性价比

- **做法**:新建 `fangzheng.json` 方证库:每方证 = {主症必见 + 或然症 + 方 + 原文条文出处 + 鉴别要点};引擎新增 `_fangzheng` 层:症状组合命中 → 结果顶部"📜 方证"卡,与六体系证型层互参(方证定方,证型释病机)。
- **首批 30 方证**:栀子豉汤、大青龙汤、小青龙汤、小建中汤、桂枝加葛根汤、葛根汤、真武汤、黄连阿胶汤、炙甘草汤、猪苓汤、吴茱萸汤、白头翁汤、半夏泻心汤、旋覆代赭汤、苓桂术甘汤、甘麦大枣汤、酸枣仁汤、温经汤、完带汤、止嗽散、桑杏汤、增液汤、玉女煎、清胃散、补中益气汤、升阳益胃汤、血府逐瘀汤、补阳还五汤、独活寄生汤、羌活胜湿汤(条文一律标注出处,查无原文者标"教材惯例")。
- **验收**:case_suite 补 15 例方证医案,方证层 PASS ≥90%;H9(栀子豉汤证)转 PASS。

### P2 辨证推理升级(查表 → 权衡)

1. **症状加权**:主诉问题内症状 ×2 权重;"但见一症便是"清单(往来寒热→少阳、消渴→厥阴等,标注条文依据);
2. **排除减分**:否定词升级为反向减分(无汗 减表虚类、口不渴 减热证类),互斥校验(苔黄腻↔舌淡白 等组合告警);
3. **舌脉决定性权重**:舌脉与症状冲突时,舌脉结论优先并明示"舍症从脉"理由(真热假寒/真寒假热的通用化);
4. **证型关系图**:`synd_relations.json`(相兼/传变/转化:太阳→阳明、卫→气→营→血、肝郁→化火→伤阴),动态推理升级为病机链可视化;
5. **主动鉴别问诊树**:按当前 top2 证型动态生成鉴别路径(如眩晕:肝阳上亢 vs 痰湿中阻 → 问"头重如裹?耳鸣腰酸?"),替代纯词触发。
- **验收**:eval 新增排除/权重/关系检查;35 医案不降;新增 20 例对抗样本抽检。

### P3 开方深度(选方 → 组方)

1. **君臣佐使处方笺**:利用 yifang 库逐药 role(君臣佐使)字段,处方笺按结构分组展示+每味药角色说明;
2. **证-量规则库** `dosage_rules.json`:30 味核心药的证-量映射(附子 3-15g 依阳虚轻重、麻黄 3-9g 依表实程度、大黄 3-12g 依腑实缓急、细辛不过钱等),全部标注来源,超限红旗;
3. **十八反十九畏/妊娠禁忌全库校验**:合方+加减后逐对校验,冲突 → 红色警告+替代建议;
4. **加减规则升级**:从"条件全命中"改为"主症触发 + 禁忌排除"(如见汗出禁用麻黄类加味)。
- **验收**:已知配伍禁忌拦截率 100%(禁忌样本集);剂量规则覆盖 30 味;35 医案方剂检查不降。

### P4 评测与真值(世界级的度量基准)

1. **独立医师标注真值集**:500 例(症状→证型→方剂),2-3 位中医师盲标+仲裁,与规则库完全独立;
2. **双盲评测看板**:规则引擎 vs DeepSeek vs 真值——准确率/召回/方证一致率公开;
3. **CI 回归**:case_suite.py + eval 进 GitHub Actions,每次 push 自动跑,分数下降即拦截合并;
4. **真实病历测试**:50 份脱敏真实病历全流程(主诉→辨证→开方→医师复核意见)。
- **验收**:第一份真实准确率报告公开;CI 门禁生效。

### P5 安全与人群修正(底线,可与 P1 并行)

1. **危急红旗全库化**:儿科危候模式推广全库(高热、神昏、胸痛、大出血、黄疸、喘脱、剧痛…),红/黄分级;
2. **特殊人群修正**:孕妇(妊娠禁忌药自动拦截)、儿童(剂量按年龄折算提示)、老人(慎攻伐提示);
3. **证据等级标注**:结论按证据等级标注(A 经典原文/B 教材共识/C 推算),五运六气/时间辨证标"C 参考",避免误导。
- **验收**:危险样本集漏报 0;人群拦截生效;低证据结论均有标注。

## 三、优先级与路线

```
P1 方证层 ──┬──► P2 推理升级 ──► P3 开方深度
            │
P5 安全 ────┘(并行)
P4 真值评测:立即启动(标注集周期长,越早越好)
```

**理由**:P1 用最小成本填最明显的经典缺口(直接让辨证"像老中医");P5 是安全底线,不能等;P4 决定"世界顶级"这个说法能不能被度量,周期最长必须早启动;P2/P3 是深度打磨,在 P1 的方证-证型双层结构稳定后做收益最大。
