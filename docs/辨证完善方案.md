# 杏林汇 · 辨证能力完善方案(基于四系统原版辨证方式)

> 检查对象:儿科《程氏家传儿科秘要》、疮疡《治疗大全》系、痔漏(周氏痔瘘)、丹药《中国炼丹术与丹药》。
> 检查时间:2026-08-28。目标:把原版辨证的精华全部收进统一辨证中心与门诊流程。

## 一、四系统原版辨证方式检查结果

### 1. 儿科(已完整接入 ✅)
- 方式:程氏四步采集(望手纹/切脉/看外症/问诊,150 项体征,每项带原著注释)→ 八症规则加权打分(8 套权重表)→ 危候/组合危候拦截 → 六字治法(平肝补脾泻心)→ 主方+加减法原文。
- 状态:**已 100% 移植后端**(engine=original,实测风热/急惊风正确)。

### 2. 疮疡(部分接入 ⚠️)
- 原版方式有四层:①疾病图谱匹配(原文特点/鉴别);②**分期治法规则**(病+分期→内治/外治/护理原文,280 条 treatment_rules);③**症状→证/方匹配**(match-syndrome/match-formula 打分);④AI 文本辨病+**Qwen-VL 拍照辨病**。
- 现状:统一中心只用了①+AI;②③④ 仍只活在旧疮疡模块里。

### 3. 痔漏(部分接入 ⚠️)
- 原版方式:病种→**结构化证型规则精确匹配**(required_symptoms 逐项核验→置信度阈值→证据链)→ 加减化裁 → 推荐方剂 → **周氏原文依据**(build_original_knowledge)→ **用药安全校验**(十八反/十九畏/妊娠禁忌/剂量)→ 治法计划(内治/外治/调护)→ 鉴别诊断 → 处方 PDF。
- 现状:统一中心只有关键词打分;**结构化精确匹配、置信度、安全校验、鉴别诊断、治法计划都没进统一流程**;门诊处方环节完全没有安全校验。

### 4. 丹药(未接入 ❌)
- 原版方式:引导式问诊(部位→疮形→脓液→全身→舌脉→特殊人群→中毒征象)→ **红旗安全闸门**(中毒征象/危急重症→阻断推荐、要求就医)→ 黄旗慎用 → 证型判定(阳证热毒/阴证寒凝等,minHits 规则)→ 按证/分期选方(每条附原书主治原文与排除理由)→ **毒龙丹引药按症匹配**(245 条)。
- 现状:完全未进统一辨证中心(丹药模块自己有一套前端规则引擎,与中心脱节)。

## 二、完善方案(按优先级)

### P0-1 处方安全校验进门诊(最高优先,涉及用药安全)
- 后端新增 `POST /api/v1/dx/safety-check`:{formulas:[方名], gender} → 逐方解析组成(来自 kb_formulas),复用痔漏原版 safety_check(十八反/十九畏/妊娠禁忌/剂量)+ 丹药毒性库(汞制剂/马钱子) → 返回分级警告。
- 前端:门诊接诊"保存就诊"前自动校验并展示警告;处方区加"安全校验"按钮与结果卡(红/黄两级)。

### P0-2 丹药原版辨证引擎接入统一中心
- 提取 assist-ontology/assist-rules(红旗/黄旗/证型/选方规则)为 JSON(与儿科同法,已在本地 kb-data 可复用);
- dx 的 alchemy 分支:问诊数据→红旗拦截(阻断+就医提示)→证型判定→按证选方(附原书主治原文+排除理由)→引药匹配;
- 前端辨证中心加"红旗警示"卡片(红色,原文+立即就医)。

### P0-3 痔漏结构化辨证升级(精确匹配+置信度+原文)
- dx 的 anorectal 分支改用原版逻辑:症状字典键精确匹配 required_symptoms(我们已有字典翻译,升级为逐项核验)→ 置信度+证据链 → 治则+加减化裁 → 周氏原文依据;
- 返回体增加 confidence/evidence/original 字段(前端展示"辨证依据"原文)。

### P0-4 疮疡分期治法接入
- dx 的 surgery 分支:选中 top 病种后,附该病"初起/成脓/溃后"三期治法规则原文(内治方/外治方/护理/禁忌)+ 名医经验链接;
- 前端辨证结果区加"分期治法"卡(按病种展示三期)。

### P1-1 拍照辨病进辨证中心与门诊
- 辨证中心/门诊接诊加"上传患处照片"→ Qwen-VL identify(疮疡/肛肠两科)→ 结果并入辨证(病种/证型/方剂)。

### P1-2 儿科加减法原文展示
- 原版 jiajianMapping 已提取,后端返回 top 症的兼症加减建议(如"夹食→加…"),前端"主方"卡下展示。

### P1-3 AI 报告强化
- 各专科引擎的结构化结果(红旗/置信度/原文)统一注入 AI 提示词,要求 AI 逐条核对并引用原文(已做一部分,补齐丹药红旗与痔漏证据链)。

### P2(数据与运营,可后置)
- 安全知识统一:丹药毒性、十八反/十九畏、妊娠禁忌并入 kb 统一数据层,跨专科共用;
- 疗效闭环:门诊随访疗效评分 ↔ 辨证记录关联,积累"证-方-效"数据供后续优化推荐。

## 三、实施建议
- 顺序:P0-1 → P0-2 → P0-3 → P0-4 → P1 → P2(每项可独立上线,不互相阻塞);
- 每项均为"提取原版数据/逻辑 → 后端分支 → 前端展示 → 实测"四步,预计每项 0.5~1 天;
- 全部完成后,统一辨证中心将具备:**儿科原版引擎(已就绪)+ 疮疡分期治法 + 痔漏精确辨证+安全校验 + 丹药红旗选方 + 拍照辨病 + 原文依据全程可查**。
