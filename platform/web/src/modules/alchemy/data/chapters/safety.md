# 安全与法规篇（现代警示）

> 本篇为《中国炼丹术与丹药》数字化系统的配套现代警示内容，依据现行法律法规、药典及公开毒理学资料整理，仅作专业学术研究参考，不构成医疗、用药或合规意见。

> ⚠️ **核心声明**：书中所载丹药（轻粉、粉霜、白降丹、三仙丹、红升丹、灵砂、银朱等）多为**汞、砷剧毒化合物制剂**。本系统保留原书临床用法原文仅为史料与专业研究之用——**严禁自行配制、严禁内服、严禁任何非专业用途**。临床使用必须遵循现行药事法规与专业规范。

## 一、现行法规管制

### 1. 毒性药品管理
《医疗用毒性药品管理办法》（1988年国务院令第23号）对毒性药品实行特殊管理。其毒性药品品种目录中，与本书直接相关的有：

| 类别 | 品种 |
|---|---|
| 中药毒性品种 | **砒石（红砒、白砒）、砒霜、雄黄、水银、红粉、轻粉、红升丹、白降丹** 等 |
| 西药毒性品种 | **三氧化二砷（砒霜）、升汞（氯化高汞）**、亚砷酸钾 等 |

本书中的轻粉、粉霜（氯化汞类），红升丹、三仙丹（氧化汞类），灵砂、银朱、朱砂（硫化汞类）及砒石、雄黄（砷类）主成分，均属该目录管控范围。

**管理要点**：
- 毒性药品须由指定药品经营单位收购、经营、加工、保管、调配；
- 每次处方剂量不得超过**二日极量**；
- 调配须凭医生签名正式处方，未注明「毒」字的不得销售。

### 2. 处方药定位
含汞、含砷药品均为**处方药/特殊管理药品**，不得按非处方药渠道随意销售；毒性中药一般不得在普通药店零售。

### 3. 流通禁令
- 《化妆品安全技术规范（2015）》将汞、砷列为禁用组分；
- GB 2762《食品中污染物限量》、GB 16740《保健食品》等对汞、砷设污染物限量管控。
- **丹药绝不能以食品、保健食品、化妆品名义生产流通。**

## 二、《中国药典》（2020年版）相关品种现状

| 品种 | 收载情况 | 用法用量与限制 |
|---|---|---|
| 红粉（红升丹） | 收载 | 外用适量，研极细粉；**只可外用，不可内服**；不宜久用，孕妇禁用 |
| 轻粉 | 收载 | 外用适量研末掺敷；内服一次0.1～0.2g、一日1～2次（入丸散/胶囊，服后漱口）；有毒，不可过量，内服慎用，**孕妇禁服** |
| 朱砂 | 收载 | 0.1～0.5g，入丸散服；**不宜大量久服**，孕妇及肝肾功能不全者禁用 |
| 雄黄 | 收载 | 内服0.05～0.1g，入丸散服；孕妇禁用；**忌火煅**（煅后氧化生成砒霜，毒性剧增）；不宜久服 |
| 白降丹 | **未收载** | 依部颁/地方标准：只作外用，**禁内服**，外用宜少量，孕妇及哺乳期妇女禁用 |
| 砒石/砒霜 | 砒石饮片**未收载** | 砒霜列毒性西药品种；亚砷酸注射液为严格管控处方药 |

## 三、毒理学要点

### 1. 汞（Hg）
- **吸收**：无机汞盐可经消化道、呼吸道及**破损皮肤/黏膜**吸收（外用丹药正是经创面吸收的途径）；
- **急性毒性**：升汞（HgCl₂）成人**口服致死量约0.1～0.5g**；轻粉（Hg₂Cl₂）毒性较低，但可被氧化、长期应用**蓄积**；
- **急性中毒表现**：腐蚀性胃肠炎（金属味、口腔烧灼、血性腹泻）、**急性肾损伤（少尿/无尿、尿毒症）**；
- **慢性中毒表现**：口腔炎（流涎、牙龈「汞线」）、震颤、易兴奋/记忆减退及肾损害；汞在肾与中枢神经系统蓄积，半衰期长。

### 2. 砷（As）
- **急性毒性**：三氧化二砷（砒霜）成人**口服致死量约0.06～0.3g**；急性中毒呈「霍乱样」胃肠症状（呕吐、米泔水样便）、多脏器损害与周围神经病变；
- **慢性毒性**：皮肤色素沉着、掌跖角化、砷黑变病、周围神经炎；
- **致癌性**：砷为 **IARC 1类致癌物**；
- 雄黄（As₂S₂）**忌火煅**：煅后氧化生成可溶性 As₂O₃，毒性剧增。

## 四、中毒救治要点（科普原则，非医疗处方）

> 仅为警示性科普，具体救治必须由医疗机构专业人员实施。

- 立即脱离毒物接触，皮肤黏膜污染用大量清水冲洗；
- 消化道摄入者尽快送医，**勿自行催吐**；医院条件下可行洗胃、导泻；
- 汞、砷中毒的特异性治疗为**巯基络合剂**（如二巯基丙磺酸钠等），需在医疗机构内使用；
- 对症支持：补液、纠正电解质紊乱、护肾、血液净化等。

## 五、历史注记：丹药为何在现代临床基本被淘汰

1. **蓄积毒性不可控**：汞、砷长期蓄积，远期肾损害与神经损害难以规避；
2. **安全替代品出现**：现代外科消毒、腐蚀、生肌手段（碘伏、银离子敷料、外科清创等）更安全有效；
3. **监管趋严**：毒性药品管理、药典收紧用法、孕妇禁用等限制使传统丹药应用空间极小；
4. **有限的研究性应用**：个别中医外科（肛肠、疮疡）流派仍在严格控制下小样本应用红升丹、白降丹，多限于难愈性溃疡等，均须在法规与伦理框架内进行。

## 六、本系统的使用守则

1. 本系统定位为**中医外科专业学术研究参考**：了解丹药的历史、理论与原书临床经验；
2. 阅读「使用」类内容时，始终将现代警示与原文同屏对待；
3. **严禁**按原书方自行配制、严禁内服、严禁用于非专业用途；
4. 临床工作者如作研究性应用，必须遵循《医疗用毒性药品管理办法》、现行药典及伦理规范；
5. 如发生汞、砷接触或疑似中毒，立即就医。
