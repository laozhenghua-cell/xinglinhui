# 第三章　氯化汞类丹药

> 原书第 55–71 页 · 张觉人《中国炼丹术与丹药》四川人民出版社1984

> ⚠️ **安全警示**：丹药为汞、砷剧毒化合物制剂，本章所述炼制与用法仅供专业学术研究，严禁自行配制、严禁内服，临床须遵循现行药事法规。

## 概述

氯化汞（HgCl）包括有轻粉和粉霜两个方面。轻粉质轻，粉霜质重。从文献上看来，粉霜的发现，是要晚于轻粉的。在早期的炼丹书中，虽未找出此物来，但在唐代王焘的《外台秘要》中却有了记载，且是引用的《崔氏方》。崔氏方是晋武帝泰始至泰兴（公元265~318年）时的作品，因此，知道我国远在西晋以前，就开始了氯化汞的炼制。

（原书第55页）

## 一、轻粉与粉霜

### 轻粉

轻粉（Hg2Cl2）又名水银粉。李时珍说：在提炼水银时，升于锅盖上的附着物，即是水银粉。它的作用，《天宝本草》说：

> "味辛凉，无毒，畏磁石、石黄。通大海（便），转小儿疳积并疗病，杀疥癣虫，风【？原文待核】燥痒"

并有一系列别名，水银粉（《本草纲目》）、水银霜（《药物异名》）、水粉（《药性要略》）、水银灰、素粉（《开宝本草》）、银粉（《药品小名》）、峭粉（《开宝本草》）、真轻粉（《外科正宗》）、腻粉（《苏颂本草》）。

（原书第55页）

### 粉霜（白降丹）

粉霜（HgCl2）又名白降丹。李时珍说："以汞粉转升成霜，故名粉霜。"葛洪《抱朴子内篇》中有此名，其他《外台秘要》中也有粉霜的炼法，且也有一些别名，如水银霜（《崔氏方》）、五色粉霜（《霉疮秘录》）、白雪（《抱朴子》）、水云银（《海药本草》）、白虎脑、赤帝体雪、吴沙汞金、金液、金银虎、沙汞（《石药尔雅》）。

（原书第55–56页）

### 轻粉、粉霜的名实与源流

轻粉、粉霜同为氯化汞，这两种东西在原料和形态上【？原文待核】相似，凡为由升华得来的氯化汞质轻，故名轻粉（在提炼水银时，升于盖上的附着物），称轻粉不太合理，因为没有食盐成分，不能称为Hg2Cl2，与红升丹对比而来的氯化汞，则名白降丹，但在中医外科所用的白降丹其处方配伍已有了不同，这两种丹药名称在历代的文献中都经常有所混淆。

关于轻粉，后唐马缟《中华古今注》上说，"秦穆公女弄玉，有德容，感仙人萧史为烧水银成霜予涂。"晋代李石《续博物志》说，"萧史与秦穆公炼飞云丹，第一转弄玉涂之，今之水银腻粉也。"李时珍则认为，这正是轻粉之始。清代郑文焯《医故》也说，"萧史与秦穆公炼飞云丹，第一转即轻粉。"查萧史与秦穆公都是公元前六世纪春秋战国时人，那时肯定是有了水银，但有无炼丹术尚难确定。

再从汉晋各代来看，也不能证实那时就能制炼轻粉。《唐新本草》中也未见有此物，因此，推想轻粉一物大致是在南、北朝或唐初的炼丹家首先发明创造出来的，可惜那一时代的炼丹书籍都已散失无存，无从找得它的操作线索来。

（原书第56页）

### 唐代《千金要方》飞水银霜法

较早见的文献只唐代（公元659~682年）时的《千金要方》中载有"飞水银霜法"，它的方法是：

> "水银一斤，朴硝八两，大醋半升，黄矾（硫酸高铁）十两，锡二十两，玄精（氯化镁）六两，盐花三两，右七味，先炼锡讫，又温水银令热，乃投锡中（是炼成合金），又捣玄精等和合，以醋拌之令湿，以盐花一斤压底，乃铺盐令平，以朴硝盖上讫，以盆盖合，以盐泥泥缝际令干，微火三日，武火四日，凡七日，去火一日开之，扫取极须细心，勿令须臾间懈慢。"

这方中的锡，是先和水银制成合金，加热后则徐徐出汞，用醋搅拌原料是取其湿而匀，参加反应的是水银、硫酸铝及食盐，其反应式如下，

6Hg + 2KAl(SO4)2 + 6NaCl + 3O2 = 3Hg2Cl2 + K2SO4 + 3Na2SO4 + Al2O3

这一制法比较合理，显然是经过一段时间摸索后得出来的成果，是唐代的常用药物，并还以它来作化妆品，可证实其质量不低，其中腐蚀性最强的粉霜（白降丹）含量也甚少（惟此处的"粉霜"二字尚欠妥），这一处方后来经过不断的使用和研究后又有所改进。

如宋代炼丹书蒙轩居士《庚道集》（公元1144年）的轻粉制法是，"汞一两，和白矾三钱许，食盐三钱许。"很接近理论原料的需要量，自此以后，我国的轻粉制炼方法，基本上已经成熟，并已固定起来。现代常用的轻粉处方是，"水银七两，食盐三两，明矾五两。"照这一处方升炼出来的轻粉，测定Hg2Cl2的含量是99.6%以上，符合药典的规定标准。王季和氏在公元1920年时曾根据《本草纲目》上的轻粉制法（水银30克，白矾60克，食盐30克）试制一料轻粉，其反应结果也很满意（见《科学》七卷五期），其反应式为，

6Hg + 2KAl(SO4)2 + 6NaCl + 3O2 → 3Hg2Cl2 + K2SO4 + 3Na2SO4 + Al2O3

（原书第56–57页）

### 《本草品汇精要》水银粉制法

《本草品汇精要》对于水银粉的制法也有详细记录，它说，

> "凡作粉要先作曲，其作曲法以皂矾一斤，盐减半，二味入铁锅内以慢火炒之，仍以铁方铲搅不住手，炒干成曲如柳青色，其升粉法先置一平台，高三尺余，径二尺，不拘砖石，以荆柴炭一斤碎之如核桃大拢于台上燃烧，每升粉一次用水银一两二钱，曲二两二钱，纳石臼内以石杵研不见水银星为度，却入白矾粗末二钱，三味搅匀，平摊铁鏊中心，厚约三分许，用鹅翎遍插小孔，将澄浆瓦盆覆之，缝以盐泥固济勿令太实，实则难启，置鏊于积火上，候微热以手蘸水轻抹其缝及盆，复用砖块立鏊下围护火气，待火尽盆温揭之，勿令手重，重则振落，其粉凝于盆底，状若雪花而莹洁，以翎扫之，瓷瓶收贮，其盆浊渣入后料再升，此法曾经修炼，详不过此。"

这一段记录有药剂的用量，有加热的温度（文火，武火），有反应的时间等条件的叙述，且有"曾经修炼，详不过此"的眼见事实，因此，相信他一定是亲眼看到过操作的，所以才能说得如此有声有色，这一操作法可用两个连续反应来说明它的过程，

1. 4Hg + 4Fe2O3 = 2Hg2SO4 + 4FeO + 2SO2（绿矾）

2. Hg2SO4 + 2NaCl = Na2SO4 + Hg2Cl2（升华）（水银粉）

（原书第57–58页）

### 氯化高汞（粉霜）的历代炼法

上面已经说过了氯化低汞，现再谈谈氯化高汞。古代常用氧化较强的原料来作升华实验，从文献上看来，轻粉的发现史，也是要早于粉霜，在西晋（公元265~316年）的《崔氏方》中，就有水银霜的制法，它的方法是，

> "水银、石硫黄、伏龙肝各十两研细，盐花一两，右四味以水银别销熬，石硫黄碎如豆并别销中热之，良久水银当热，石硫黄消成水，即并入一处中和之，宜急倾并（若不急则结合得不彻底，就有某方过多或过少的不均现象而损害丹的使用价值），并旋下火急搅，不得停手，若停手则水银即别在一边，搅之良久，硫黄成灰不见水银（是结砂已经完成的现象），即与伏龙肝合搅令调，并合盐末搅之令相得，别取盐末罗于销中令遍底，厚一分许，即以盆覆销，以灰盐合土作泥涂其缝勿令干裂，裂即涂之，惟令勿泄炭火气，飞之一伏时开之，用火先缓后急，开旋以老鸡羽扫取，皆在盆上，凡一转后即分为四份，以一份合成霜研之令匀，又加二两盐末准前法飞之，弃其土，又以一份土和飞之，四份凡得四转，及初飞五转，每一转皆弃其土，五转而土尽矣。若须多转更须新土依前法飞之，如此七转而霜成已可用之。"

这一方法经研究后，与《千金翼方》的水银霜却不相同，从制备轻粉的长期实践证明，硫化汞与氯化钠也不易置换而得粉霜。伏龙肝一物是经过长期煅烧的粘土，很可能作为生成硫酸的催化剂，欧洲早期的制硫酸法也曾用过一种土壤来作催化剂（接触剂），其反应式如下，

Hg + S → HgS

HgS + 2NaCl → HgCl2 + Na2S

这一方法确有制得粉霜的可能，但催化剂是不易置换的，如选择不当，即不可能制得粉霜。

《庚道集》是宋绍兴甲子年（公元1144年）作品，其中的升粉霜法，则比较接近实际，它的方法是，"水银一两、明矾二两、食盐一两、火硝六钱。"其反应式如下：

Hg + 2NaCl + Al2(SO4)3 + 2KNO3 → Na2SO4 + K2SO4 + Al2O3 + O2 + 2NO↑ + HgCl2

这一方法的特点是，处方中使用了火硝，氧化作用强，生成粉霜的反应较完全，而且原料用量少，操作方法简便，都比崔氏方法为进步。但是，我国制造粉霜的经验，在12世纪时，并不能说是已经成熟，从名称经常混淆这一点上看来，已充分表现出那时尚不能鉴别出轻粉和粉霜的各自不同。

医家的化学知识虽然说比炼丹家差，但医生必须知道药物的毒性问题，所以，在明代以前的医书中，用粉霜的远不如用轻粉者来得多，他们在外科临床时，把粉霜同轻粉常给以显著区别的名称。如《外科正宗》及《疡医大全》中，则称之为白降丹，现代医学则称升汞为白降丹，其处方亦与《庚道集》基本符合，但有时也加入少量的雄黄和硼砂，惟不能参加到主要作用中去。硼砂是助熔剂可以加速反应，不过一般的炼丹家多不加入这两种原料。

在化学史上，谈到氯化高汞历史时，都说是始于八世纪的亚拉伯炼金家 Ceber（公元702~765年），如此说来，Ceber 的方法则比我国《崔氏方》要晚四百多年，他的氯化高汞制法，是用以下原料，经过升华而成的，

"水银一磅，硫酸二磅，明矾一磅，食盐一磅半，硝石2.25磅。"

这一方法，在欧洲应用了相当长的时间，直到1793年，据 Hildebrandt 报告，可用下列处方，经过升华而得氯化高汞，

"水银三分，食盐二分，煅制铁矾四分，硝石四分。"

3Hg + 2NaCl + 2KNO3 + Fe2O3 → Na2SO4 + K2SO4 + Fe2O3 + HgCl2 + 2NO2↑

因为这一处方的效果，比 Ceber 法好，故将其地位取而代之，欧洲则称之为老荷兰法，把老荷兰法来与《庚道集》作一对比，则根本也很相同，但也有一点区别处，就是他用铁矾来代替了明矾。荷兰人在学习这一方法后，为什么会有此改变？原因是欧洲在17~18世纪时，是用蒸馏法煅制铁矾来制作硫酸，且此物较明矾易得而价廉，故有此改变。

（原书第58–60页）

### 轻粉与粉霜的鉴别

我国古代对轻粉及粉霜两物，在初期制用时，经常混淆而无所区别，因此，统称之为水银霜或粉霜，但粉霜的毒性要比轻粉强得多。宋代以前，因服食金丹药物致死或中毒的悲剧经常发生，而且包括许多帝王及大臣在内，这些不幸悲惨事件的发生，当与粉霜有关。因此轻粉与粉霜的鉴别，便成为了炼丹家和医药家必须解决的问题。

宋代炼丹书《太清石壁记》中，首先认为这两物是有区别的，因此，它作出了如下的一个划分，

制轻粉法，水银500克，食盐1000克，朴硝120克，太阳玄精180克，敦煌矾石（或绿矾）经升华后而得轻粉。

制粉霜法，朱砂1000克，铅45克，黄矾30克，及伏龙肝，食盐、朴硝、硼砂等，经升华后而得粉霜。但是其中的制粉霜法把握不太大。

将两物区分得更清楚的炼丹书是《灵砂大丹要诀》，它的方法是：

制轻粉法：是以水银、皂矾、食盐经升华而成轻粉。

制粉霜法：是以水银、皂矾、火硝、食盐、信石经升华而得粉霜。信石可以不用，现在的白降丹则有用信石者。

从宋朝时起，我国炼丹家的目标，即逐渐朝着医药方面转移，故此时期中炼丹家的炼丹工作和医药家的治疗工作联系在一起。如宋代《苏沈良方》中的妙香丸处方，即有了粉霜3克，腻粉9克的记载，元代齐德之《外科精义》中的寸金丹处方中，也有轻粉3克，腻粉9克的记载。这说明了，我国在12世纪以前，即已经把轻粉和粉霜在化学及医疗上分别开来。

我国炼制这两种氯化汞的区别点，是在有无火硝。有火硝者，则得粉霜，无火硝者，则得轻粉，不过粉霜的质量是不太纯的。

（原书第61页）

### 《本草品汇精要》粉霜法与近代粉霜炼法

《本草品汇精要》所引用的粉霜制法，较明代以前的各家方法都进步，其法是，

> "用焰硝、食盐、白矾、皂矾各500克，入铁锅内炒熔成汁，急以铁铲频搅结成黄色砂子，谓之粗曲，内石臼中以铁研极细，谓之细曲，入水银500克研令不见微星为度，谓之汞曲，分成四份，先以阳城罐长五、六寸者，用细炭灰500克，入盐180克，水和得所，留罐口二分许，周围固济，晒干纳汞曲一份于内，上用铁灯盏以绳缠束极紧，外用盐300克，白炭灰500克，水和为泥捏作饼子烧通红，待冷研为细末，水调得所，用小竹竿三、四寸，周围离缸二寸用砖数块围成护，煤用2公斤，炭用1公斤。火候之法先文后武，煤、炭陆续旋涨，上勿近盖，待僵热时徐徐添极热水（或许是冷水之误，因为碗中贮水目的是在使其起冷却作用，故肯定说这一热字是冷字之误），只可九分满，水少即添，常令水足，仍以铁盏边滚为度，如药慢通滚为火大，火大则罐必裂，慢慢滚起为火小，火小则粉不升，水上火下（是水火既济炉）故欲其相济，别点长香以三炷为则，到二炷香尽时火方渐渐与盖相平，至三炷香完即便去火，莫动其罐，待极冷时取出共研细末，通入一罐，如前法再升一遍，其色渐白，状如寒水石，一般方药用也。"

照这一方法炼制出来的粉霜最为理想，故一直沿用到现在。

近代粉霜炼法：

近代粉霜是用轻粉转升而成，其法是将轻粉置阳城罐中，密封罐口，置锅内砂中（须深入砂中，比内容物约高3～4厘米），徐徐加热升之，升华终了，将罐取出，和破坏其封口物，放置之，候冷，则升华物自然剥离，研细飞取细末于滤纸上，以水、酒精等顺次洗涤，然后以微温干燥之即成。这一方法，是从《本草纲目》衍化出来的，因其是由轻粉再度加工而成，故其成分是与轻粉一样，同为氯化亚汞，故无毒。

（原书第61–62页）

### 笔者的轻粉炼制法

处方：水银300克，青矾150克，食盐150克。

1．将青矾研细，放拌料盘中，加入水银、食盐混合后，再加清水少许，搅和均匀成干糊状泥团，以不见水银点为止，轻捏之能成形，轻击之能散为最好。如水加得过多，则水银升华与水气蒸发结聚钵上成黑砂，过少则烧丹时胎易裂散，影响升华及扫取丹药困难。

2．取拌搅好的药料，放平底铁锅中央，用竹片轻压成饼状（烧丹胎），上盖瓦钵，锅与钵接口处先用盐泥固济，再以河沙围护，勿使漏气走丹。

3．将锅移于燃火炉上，先用文火烧5～7小时，继用武火烧7小时，后又改用文火6小时，离火待冷。时间和火候均须细心掌握好，否则丹药色不纯白。火大则色灰，火小则成棉状物。

4．取丹时，先在河沙周围洒水少许，然后除去河沙，揭开瓦钵，扫下丹药，工作即告完成。

（原书第63页）

### 红粉、轻粉的制造经验（刘文采、汉祖良）

刘文采、汉祖良两同志介绍的"红粉、轻粉的制造经验"是大规模的生产方法，颇有学习价值，故现将轻粉部分转录于下，以供参考。

1．原料：水银3120克、胆矾1700克、食盐2000克、红土约10斤、大碗

2．设备：作坊一间，长9市尺，高6市尺，宽6市尺，内设砖砌炉台，高60厘米，左右各设炉眼4个，正面开炉眼2个，共计炉眼10个，每一炉眼置铁质平底锅一口，以搪瓷盆作盖即在锅边。

3．制料：先将胆矾和食盐放于瓷缸盆内，加水约1.5公斤，溶合后放入水银搅拌成糊状，再加入红土拌成半湿半干的软泥体，分为10份捏成馒头形，另在平底锅中央稍放一层极薄的干沙土，面积与馒头形泥体大小相同，将10个软泥体置沙土上，再将每个瓷盆覆上，用潮湿的黄沙土封固以防透气，先放在炉外待点火上炉。

4．制炼：每炉（计10锅）约用银炭（即上等木炭）47斤，先在炉外燃烧，待烧至红火均匀只有少数黑炭时始为适当，再分拨到各炉眼内，待略燃片刻即进行通火，将炉腿中央摆成空形，只见有火苗之处即用炭盖住，不使火苗上燃，再将炉房门关闭开始闷火，等到炭火无火苗，四周炭火呈有白灰时，将已封闭平锅放于每个炉腿上，锅底离火约1厘米，将炉门关闭，过22小时后开锅，则见原土馒头形上和锅里呈现似雪花的多角形片体，用鸡翎扫起，拣出杂质，即为轻粉。每炉产量，由于操作技术关系和火力过大或过小等原因，每次所得产量高的达2180克，低的约1120克。每次成曲烧出后，其泥土沙的锅底里还含有一些残余的水银，故仍能作红土的制料使用，继续烧出轻粉来。

5．注意事项

（1）炉房大小，炉台高低，炉眼大小，安装设备等均很重要，须特别注意。

（2）炉房干湿程度和炭强弱必须适宜。如火力过大，则烧出成品片厚，体重，色发乌，无光，水银亦容易烧飞，受到损耗；如火力过小，则烧出的数量少，片小，体轻象棉花绒，色白无光。因此，火力过大或过小都可影响质量。在掌握火力上，一般须通过实际经验，才能找出规律。

（3）这段文章有犯生搬硬套，对号入座之嫌，但为了参考需要，不得已而摘录了全文。

（原书第63–65页）

## 二、中九丸

### 缘起与处方

中九丸是中药的一个化学制剂，为《外科十三方》的首一方，是一直流行在我国西南地区民间医生中的一个秘方。由于历史条件影响，致持有此方者都极端保守，讳莫如深，不肯轻易告人，即偶有传授者，亦大多改头换面，故意抽添，使此方十人十样。我为了求得正确方法，曾先后拜访过七位使用中九丸的老师，得来方法都各不尽同，甲说甲方是真传，乙说乙方是秘授，使人如堕五里雾中，不得已只好将所得各方从临床实践中寻求解答，并作过动物实验，经过无数次实践后，得出现在这一配方比较满意，曾经使用达六十年久，无往不利，故特公开出来给四化献礼。

处方：水银30克、火硝30克、白矾30克、皂矾30克、食盐30克、朱砂15克。

（原书第65页）

### 灵药三打炼法

炼法：除水银、朱砂外，将其他各药研匀，放于锅底中心，以文火加热，少顷即可看到锅中药物熔成液体，慢慢即由液体变成固体，此时即可将锅从火上端下待冷，冷后即将药物铲出研成细末，平均分成三组备用。

1．将第一组盐、矾、硝、皂末同水银、朱砂混合起来，研至极匀后，放于锅中赶平，然后覆上丹碗（药物面积不可超出碗口），以棉纸捻条浸湿塞在丹碗周围锅边接合处，再将熟石膏粉用盐水调成稀糊浇于碗口周围压平，约数分钟时，石膏即行硬化。此时即将筛过河沙（须稍带润湿）扒在锅中掩护丹碗，但须露出碗底，并放大米一撮以测火候，再以较大鹅卵石一颗压之，防止炉在煅炼过程中锅中水蒸气冲开丹碗走丹，一切都部署好后，即可上炉烧炼。初用文火半小时，次用武火半小时，后再用文火六小时，此时可看碗底大米是否已焦，如米未焦，可再延长一点时间。火候到时，即停火待冷，锅冷之后，即将河沙轻轻除去，并用小刀刮去碗周石膏（手势须轻，勿使碗中丹药掉入锅底，减少丹的收获），揭开丹碗，即覆于已铺纸的潮湿地下，约二小时，即将丹碗取起，以木棒从碗底轻轻敲击，丹药即全部脱下，是为一打灵药，丹底不用，丹药颜色每次不同，第一次灵药是棕黄色。

2．将第二组盐、矾、硝、皂末同灵药混和均匀进行二打，二打程序与一打一样，这次灵药是浅黄色，可收下进行三打。

3．将第三组盐、矾、硝、皂末同灵药混和均匀，进行三打。三打手续仍与一打一样，这次灵药是灰白色。丹经三打之后，水银毒性已足，故服后即不会有汞中毒之处。

（原书第65–66页）

### 金丹炼法

处方：倭铅（如无倭铅，可用黑铅代替）30克　广丹60克

炼法：将广丹先入耐火缸中，武火加热烧红后，于广丹中心撑一个窝，放入黑铅，再将丹周围掩盖，借铅气熏蒸，约半小时即可蒸透，烧至黑铅化尽不见黑珠为度，将锅离火待冷后用罗筛筛去残渣不用，如铅渣不尽服后便有引起腹痛，且能招致口吃。

金丹在外科书中指的是黄丹，即一氧化铅，红丹则是四氧化三铅，通常叫做广丹或者水丹，而《外科十三方》的金丹则是黑色粉末。这应该是一氧化二铅。铅在空气中常氧化而生成一氧化二铅，其表面失去光泽而变黑，若与空气和水共存时，就生成氢氧化铅，再受热失水，即成黄色的一氧化铅。若在试管中灼热通入干燥蒸汽，则有水蒸气放出，而形成水珠。也有把金丹称做锅上凡者，是作丹的讹称。因为金丹是由倭铅、广丹配成，故应称倭丹，而不该称锅丹。

（原书第66–67页）

### 石青炼法

处方：硫黄120克、白矾60克

炼法：将硫黄、白矾二物共研极细，入耐火罐中，上盖铁板一块。随以铁丝缚紧，再用盐泥将罐全部厚涂一层。候干后放于炉上烧之，约一小时取下待冷。冷后剥去泥壳（手势须轻，勿使盖上升华物掉入石青中），升于盖上色如黄芽者，为烟硫；沉于罐底色带暗青者，为石青。将此暗青色物取出，研成细末备用。如冷后缸中物不易取出者，可将罐子在火上旋转烘之，使缸壁稍热即可取出，也可将罐击破取出。烟硫、石青虽然同出一本，而性质却截然不同。盖烟硫有毒（因其含有较重的三氧化砷），而石青无毒。

烟硫之性好走，善入肌肤，为祛风邪，除湿气，疗诸疮之有效药物，而师成子《灵药秘方》中的灵药，即是烟硫。且是专供内服，作为丹头，配以各种引药，治疗各种疾病，这是值得研究的一个问题。

石青在中医药物和矿物中，都指的是碱式碳酸铜，与孔雀石的成分大同小异。而《外科十三方》中的石青，则名为石青，而实非石青，实际上是雄黄和雌黄的混合物。雄黄为桔红色，在闭管中灼热，则成红色液态，雌黄为柠檬黄色，在闭管中灼热，则升华，在火焰中灼热，则显苍白色火焰，能溶于浓硝酸，也能溶于氢氧化钠或氢氧化钾溶液中，使铜盐溶液生黑色沉淀，使铅盐溶液生黄色沉淀。

（原书第67页）

### 银脆炼法

处方：纹银（可以银币代替）30克、石青约30克

炼法：将银锤成薄片（银币则不必锤片），放于耐火罐中，武火熔化。至熔化时，即徐徐投入石青末，并徐徐搅拌，银即自然起发（即发泡疏松），石青不限定30克，总以银质发泡疏松为原则，发透后，倒出置于乳钵中，加水研末，水飞，晒干备用。

银脆为灰黑色粉末，根据《外科十三方》的制备过程，其主要成份应是二硫化银，能溶于稀硝酸或稀硫酸中。

（原书第68页）

### 四味异药性质

灵药：味辛，性平，无毒，功能去湿，杀菌，涤痰，镇吐。

金丹：味甘，性平，无毒，能镇吐逆反胃，涤痰，杀菌。

银脆：味辛，性平，无毒，用于外科药中，能治奇怪痰疾，生肌，敛口。

石青：大热，能解水银、轻粉之毒。因含有矾石，故善治一切风湿筋骨肿痛等症，又能解一切寒凉药毒和疮疡久不收口，作寒作热等症，也能引导水银化合物轻粉循行筋骨，以除周身寒湿，为诸药中之极热者，不可不用，但不可多用。

灵药除配入中九丸中作内服剂外，尚可照红升丹、白降丹用法，把它运用到一切疮疡方面，可获得与红升丹、白降丹的同样作用。

（原书第68页）

### 配合与用法

配合：灵药30克，金丹30克，银脆15克，石青15克，用大枣蒸熟去核，研烂如泥，然后同药末捣匀为丸（枣内水分过重者，则影响成丸，久置发霉变坏，故必须先以文火烘去水分，然后配药）。有一段时间，我曾改用面粉为丸，很奇怪，给兔食之，兔即死亡；而以枣肉制成的丸，兔食之，并无死亡，尚找不出原因（在大量制丸时，则可将枣烘干碾成粉末，筛去枣皮使用）。丸如梧子大备用。

丸制成时，必须烘至十分干燥，方可装瓶。如稍有润湿，则放久后仍会发霉。配方中的朱砂，也可不配入方中烧炼，而用来作丸衣。

用法：每次服丸五粒，每日早晚各服一次，以温开水送服。患在上部者，饭后半至一小时服；患在下部者，饭前一小时服。有极个别人有过敏者，服丸之后，有头昏或腹痛等不良反应者，为了安全计，可先由每次3粒服起，服至一周，无不良反应时，可再加服1粒，直至5粒为止。此是金石丹药，故最多不能超出5粒（但也有人需服上10粒方有效者，是属例外）。如由外伤引起的骨关节结核病，则须兼服可马散，并且定要加麝香少许，浸于白酒中，冲开水送服，如此则收效更速。局部外伤，则用金龟下海丹，调蓖麻油涂抹（须以调药竹片尽量将药抹入毛孔），二至三日一次，候腐尽时，则以天然散收口。

（原书第68–69页）

### 适应症

适应症：中九丸的一般治疗重点，大都用于阴症、骨关节结核、疔病、痰核、梅毒、乳瘤和风湿性关节炎等症。其他治症尚多。一切阳证，则不相宜。近来有人试用于癌瘤，据说对于初起癌瘤有控制作用。我认为此药对于癌瘤的治疗大有希望，尚需作进一步的探讨。

有的患者，在未服丸前，患部不痛。服丸之后，反现痛者，是药力到达病区的斗争作用，可不必有顾虑，经一、二日后，即会自行消失。

（原书第69页）

### 副作用与解药

此种由炉火炼成的金石丹药性质比较燥烈，有极个别病人服食之后，有牙龈肿痛，咽喉干燥，小腹微痛，头痛及大便燥结等副作用，可用下面药物解之。

1．现牙龈肿痛者，用生地9克，丹皮9克，地骨皮19克，薄荷3克，鲜石斛15克，射干9克，煎水服。

2．现小腹痛者，用金铃炭9克，炒栀子6克，吴茱萸6克（黄连水炒），黄连3克（吴茱萸水炒），青木香15克，银花炭6克，煎水服。

3．现头痛者，用石决明21克，白蒺藜12克，龙胆草15克，旱莲草6克，夏枯草21克，牛膝9克，丹皮9克，甘草3克，煎水服。

4．现大便干结者，用麻油30克，蜂蜜30克，开水冲服，或蜂蜜30克，玄明粉18克，煎水服。

5．溃孔因感冒发炎，头身均发高烧者，用生石膏15克，枯芩9克，焦栀6克，麦冬9克，玄参9克，鲜芦根18克，煎水服。

以上这些不良反应，仅是极个别病人偶而有之。绝大多数病人都是不会发生这些反应的。所介绍的五个解药方，仅是有备无患的一个准备。

中九丸功能解毒清血，通经走络，健筋透骨，对于阴疽恶毒，阴阳夹杂之偏于阴者，及漫肿无头，皮色不变，肌肤木硬，日轻夜重等疾患均适于用，未成者消，已成者溃，和平稳妥，尤以骨关节结核和疔病症为最常用，最有效。在洒尔弗散（六〇六、九一四）未出世前，对于梅毒一症，曾普遍应用中九丸，有良好效果。

（原书第70页）

### 治疗须知

骨关节结核和疔病都是一种最顽固的慢性病，不是十天八天服药能收到多大效果，故在治疗前，必须向病者预先说明，要将信心和耐心，作长时间的服药，才能有所收获。并要胸襟开朗，心情舒畅，思想达观，切戒发生急躁及悲观情绪而影响治疗。

结核菌对药物的抗力大，但组织的抗力亦大。从局部看，创口虽小而内部却是很深，愈合也较慢，所以药需要多服，久服，方可获得理想效果。有时从表面上看创口已合，皮色也转好，孰知再过十天或半月后，又从原处破溃出脓。这种现象并不是服药无效，也不是旧病复发，而是因为窦道过深，内部的新组织没有完全填平损害部分，收口过早的关系，因此不要停药，待内部损害部分得到新生肉芽填平时，才算根本痊愈，不要因为疮口复破而失掉信心，放弃治疗，功亏一篑。

骨关节结核及疔病病人，因为久病，故大都体力衰弱。在治疗期间，切戒过度劳动、房事和动气等不利身体事项，同时还要兼服强壮滋补药物，以资辅助。

（原书第70–71页）

## 本章要点

- 本章所述氯化汞类丹药包括轻粉（氯化亚汞 Hg2Cl2）与粉霜（氯化高汞 HgCl2，即白降丹）两类；粉霜的发现晚于轻粉，我国远在西晋以前即已开始氯化汞的炼制。
- 轻粉、粉霜因原料与形态相近，历代文献中名称长期混淆；至宋代《太清石壁记》《灵砂大丹要诀》始明确区分，关键区别在于是否用火硝：有火硝得粉霜，无火硝得轻粉。
- 原书列举了《千金要方》飞水银霜法、《本草品汇精要》水银粉制法、《崔氏方》水银霜法、《庚道集》升粉霜法，以及 Ceber、Hildebrandt（老荷兰法）等中外历代炼法，并附化学反应式。
- 中九丸是《外科十三方》首一方，为西南民间秘方；以水银、火硝、白矾、皂矾、食盐、朱砂经"三打"成灵药，再配金丹、银脆、石青，以大枣肉为丸。
- 金丹、石青、银脆为中九丸的异药成分，各有独立处方与炼法；四味异药（灵药、金丹、银脆、石青）性质、功用各异。
- 中九丸主治阴症、骨关节结核、疔病、痰核、梅毒、乳瘤、风湿性关节炎等，原书并载服后副作用的五个解药方及治疗须知。
