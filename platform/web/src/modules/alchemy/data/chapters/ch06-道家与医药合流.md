# 第六章　古代道家炼丹术与医药合流

> 原书第 31–34 页 · 张觉人《中国炼丹术与丹药》四川人民出版社1984

> ⚠️ **安全警示**：丹药为汞、砷剧毒化合物制剂，本章所述炼制与用法仅供专业学术研究，严禁自行配制、严禁内服，临床须遵循现行药事法规。

## 一、炼丹术与医药的合流

前面已谈过不少中国炼丹术的发生与发展情况，现在结合到医药上来谈谈祖国医药上的丹药炼制和用途，并具体说明祖国外科丹药的特性。

（原书第31页）

## 二、炼丹术是化学的先导，炼丹家多兼通医术

炼丹术是我国道家从两三千年漫长时间递沿下来的一种特殊技能，不仅医药上的丹药是由它衍变下来，而且还是现代化学的先导（这是搞化学史的人老早就承认了的），因此，我们在研究丹药时，对于古代搞炼丹工作的杰出人物及其炼丹过程和使用工具等，都必须有一系统了解，知道它是怎样发生及如何进展的，也必须如此，才不致犯“数典忘祖”之嫌。

> 葛洪说：“治金丹术者宜兼通医术。”

故历代的炼丹家大都兼通医术（民间也有“医道通仙道”的说法）：

- 东晋时的葛洪撰有《玉函方》百卷，《救卒方》三卷（见《抱朴子·杂应篇》）。
- 梁代弘景撰有《神农本草经注》七卷，《肘后百一方》三卷，《效验施用药方》五卷（见《华阳陶隐居内传》）。
- 唐代孙思邈撰有《千金方》三十卷，《千金翼方》三十卷，《千金通方》二十卷，《神枕方》一卷，《医家要妙》五卷（见《新唐书·艺文志》）。

在《道藏》中，也收入有《孙真人备急千金方》九十三卷，另《目录》一卷（见林亿等校正《金史》卷一百三十一）。

（原书第31页）

## 三、丹名的演变：炉火丹药与合成丹剂

古时的丹，都是由炉火锻炼出来的无机化学药物，可是后来却有了不计其数由动植物等配合成的锭剂、散剂、丸剂等成品药物，也把它称做了丹。例如天王补心丹、孔圣枕中丹、飞龙夺命丹、太乙玉枢丹、紫雪丹、经进地仙丹等。这样一来，就不免使真正丹药有了鱼目之嫌，且这类丹剂拿内容来说，与由炉火锻炼出来的丹剂，根本上也是毫不相涉的。日本冈西为人氏曾从满洲医科大学中国医药研究室所藏有的一千六百多种中国医书中，汇出丹药方名2405个列为一表，名为《丹方研究》。这二千多个丹药方剂，除了极少数是由炉火炼成丹药外，其余99%的都是合成的丹剂。这些合成丹剂名称，在唐代以前的医药文献上，是很难见到的，直到宋朝的《圣济总录》及《和剂局方》等方剂书中，才开始有了记载，因此，可以看出，合成丹剂的丹药名称，是在宋朝时才开始有的。

（原书第32页）

## 四、太平惠民和剂药局与《太平惠民和剂局方》

在世界医政史中，中国有一特殊史页，即宋徽宗时创立的“太平惠民和剂药局”，此项医政不但世界各国罕有先例，即在我国虽有继起者，而其制度的完密，也仅有赵宋一朝，盖在宋以前既未有其例，元、明以降也未发扬光大，清则竟至中绝而湮没无闻，这项医政是适应当时环境需要而产生的，和剂局的前身是宋熙宁九年（公元1076年）创置的“卖药所”，当时因了创置药局，故有《太平惠民和剂局方》一书行世，而世界之药局则创始于18世纪英伦，其晚于我国已五百年，这是我们堪以自豪的一件光荣创举。

（原书第32页）

## 五、《局方》丹剂出于道家及其衰落

《局方》的方剂来源，是由当时的封建皇帝命令派人四出向民间广泛收集来的验方、秘方，故有不少成方都能解决疑难大症问题。如至宝丹、紫雪丹等，至今尚广泛地在民间沿用。书中丹药方剂，有不少都是出于道家者流，如南岳魏夫人的“震灵丹”，丹阳济大师的“经进地仙丹”，“玉华白丹”等，都是从《道藏》中得来的。

从这些材料上看来，可以说明宋代医方中的丹剂来源，绝大多数是由丹道家所掌握的特殊资料；但到宋间以后，遂逐渐衰落下来，它的部分有治疗作用的内容，则被转入到各有关方书中，因此，得以保留下来未被淹没；又因为人们对于炼丹术具有深刻的印象和信仰，所以把民间的许多验方和秘方都命名为“丹”，如象前面所说的二千四百个丹剂名称，都是依据这种情况而产生出来的。这些丹剂，与古代由炉火中锻炼出来的丹剂，从根本上是有所不同的。宋代的方剂，多重用砒、汞、金、银、铅等金石品物，而且所用剂量还特别大，因此很易引起中毒，这自然是受了炼丹术影响而得来的后果。故宋代以后的医家，都反对这种冒险性的配伍用药法则。反对最力者，则为元代的朱丹溪，他所写的一本《局方发挥》，就是针对《和剂局方》的一个书评，他认为《和剂局方》对人民的健康来说是害多利少。因此，在金、元以后的方剂中，砒、汞等有毒药品，就逐渐地减少下来。虽然还有以朱砂、雄黄等物作丸衣的，可是用量却微乎其微，几乎不起治疗作用，且与宋时的大量采用砒、汞化合物作配料的有了根本上的不同。

（原书第32–33页）

## 六、炼丹术的盛衰与丹药在外科的价值

两晋、南、北朝（公元265—617年），是炼丹术最活跃的一个时期。葛洪就是这时期中的代表人物。在这时期中的时代背景和炼丹者的中心思想，是在“点石成金”和“长生不死”，这一幻想虽然未得实现，但在当时却曾迷惑过不少的群众，不过脱离实际的幻想行为，是经不起长期考验的。故在这以后的人，对炼丹术遂逐步由怀疑而转为不信任。经元、明、清诸先进者之一攻再击后，直到现在基本上是已告绝迹。丹药虽然不宜于内服（也有少数丹药是可以内服的，如三打灵药配成的中九丸及混元丹等），但对外科疮疡方面却有着它的不朽之绩。中医外科方药中丹药，实占有相当大的比重（谚语有“红升白降是外科家当”，可见丹药在中医外科上的重要性），故截至目前为止，任何中医外科文献中，都少不了有丹药的一个重要部分，而它也确能发挥出它的优越性来，因此，我们应很好地加以继承和发扬。

（原书第33–34页）

## 本章要点

1. 炼丹术是道家递沿的特殊技能，医药上的丹药由它衍变而来，且是现代化学的先导；葛洪以下历代炼丹家多兼通医术（葛洪、陶弘景、孙思邈等均撰有医药著作）。
2. 真正丹药本指炉火锻炼出的无机化学药物，后来大量动植物配合的锭、散、丸剂也被称为“丹”；日本冈西为人《丹方研究》汇丹药方名2405个，其中99%是合成丹剂，此类丹名至宋朝方书中始有记载。
3. 宋徽宗时创立的太平惠民和剂药局（前身为宋熙宁九年、公元1076年创置的卖药所）是世界药局的先例，早于18世纪英伦约五百年；《太平惠民和剂局方》方剂多来自向民间收集的验方、秘方。
4. 宋代医方中的丹剂多出于道家者流（如震灵丹、经进地仙丹、玉华白丹等，出自《道藏》），且重用砒、汞、金、银、铅等金石品物、剂量特大而易中毒；朱丹溪《局方发挥》力加反对，金、元以后砒、汞等有毒药品用量渐减。
5. 两晋南北朝是炼丹术最活跃时期，以葛洪为代表，中心思想在“点石成金”“长生不死”；幻想破灭后炼丹术渐衰，经元、明、清渐告绝迹。
6. 丹药虽不宜内服（少数如三打灵药配成的中九丸、混元丹可内服），但在中医外科疮疡上占重要地位（“红升白降是外科家当”），应加以继承和发扬。
