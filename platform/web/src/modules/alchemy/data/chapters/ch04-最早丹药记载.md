# 第四章　古代文献中最早见的丹药记载

> 原书第 12–14 页 · 张觉人《中国炼丹术与丹药》四川人民出版社1984
>
> ⚠️ **安全警示**：丹药为汞、砷剧毒化合物制剂，本章所述炼制与用法仅供专业学术研究，严禁自行配制、严禁内服，临床须遵循现行药事法规。

## 一、《周礼》疡医"五毒"之药与郑玄注

> 《周礼·天官冢宰篇》疡医论说："疡医掌肿疡、溃疡、金疡、折疡之祝药劀杀之剂，凡疗疡以五毒攻之……凡有疡者受其药焉。"汉末（公元126一200年）时郑康成注说：止病曰疗，攻，治也，"五毒"，五药之有毒者，今医方有五毒之药，作之合黄堥，置石胆、丹砂、雄黄、礜石、慈石其中烧之，三日三夜，其烟上著，用鸡羽扫之以注创，恶肉败骨尽出。

他所说的黄堥，是炼丹时所用的陶瓷器，因此它是用黄土做的，故叫黄堥（即现在所用的阳城罐）。《集韵》注说，"与瓦器同。"《辞源》注说，"同缶，瓦器也。"《证类本草》雄黄条注，"黄堥，若今市中所货有盖瓦盒（古时也叫做合），近世合丹药犹用黄泥瓦罐，亦名黄堥，事出于古也。"从各家解说看来，都一致承认黄堥是烧炼丹药的丹罐。

（原书第12页）

## 二、《周礼》成书年代与郑玄生平

《周礼》是书名，相传为周公居摄以后所作，拟周室的官制，但书成而未付诸实施。造作时是在公元前一千一百年，注释人郑玄是东汉时高密人，字康成，生于汉顺帝永建二年（200年）【原文如此】，卒于汉献帝建安五年（200年）。根据近代专家考证，《周礼》一书乃战国（公元前770~221年）时人所作，即使此说成立，那末中国医药史上使用化学制剂也有1000多年的历史。

（原书第12页）

## 三、"劀""杀""祝药"释义

劀音刮。刮去恶肉，除去脓血也。杀是以腐蚀剂杀去恶肉（已坏死的组织），这是以手术同药物的混合处理。祝药即现代外用敷药。

（原书第12页）

## 四、五毒之药的化学解读

石胆是石胆（硫酸铜）。丹砂是硫化汞。礜石是砷黄铁矿。慈石是四氧化三铁。雄黄是硫化砷，这是一个具有腐蚀作用的丹药。从"恶肉败骨则尽出"的说明看来，是类似今天的白降丹（氯化高汞）的一种丹药，只是它的制度是升而不是降的不同。其烟上著，就是升华的结晶，因其加热操作达三昼夜之久，故汞已大部散失，但还是残留一部分，故有"有恶肉败骨则尽出"的腐蚀作用。其反应式如下：

```
CuSO₄ → CuO + SO₃↑　　SO₃ → SO₂ + O

HgS + SO₃ + 3O → HgSO₄ + SO₂

HgO + 9O【？原文待核】

或 HgS + 3O → HgO + SO₂
```

当十六及十七世纪时，普鲁士人学习了阿拉伯人的经验，在北屋（Nordhausen）用硫酸低铁，经蒸馏而得含有SO₃的硫酸，故当时称此物为北屋酸。

```
4FeSO₄ + O₂ + 2H₂O → 4FeSO₄(OH)

4FeSO₄(OH) → 2Fe₂O₃ + 2H₂SO₄·SO₃
```

郑玄记载的为硫酸铜，基本上是同一道理。这一升华产物，是含有砷化合物的氧化汞，此氧化汞即类似后世一般中医外科红升丹。但红升丹的配方中，一般都是不用磁的，磁只可加入白降丹配方中，故五毒之药又酷似现今的白降丹。欧洲在十三世纪时（公元1235一1315年），始由Lully开始记载了氧化汞（新药中则叫做黄降汞或商科氧【？原文待核】）的制炼法，同我国郑康成时代对比起来是要晚一千多年。

（原书第13页）

## 五、胡洽水银丸——最早的汞利尿剂

利尿剂，是由我国南朝时（公元420一489年）的胡洽所发明。胡洽居士，他所著的《百病方》记载了水银丸利尿，治大腹水肿，利小便。方是姚同【？原文待核】、芝区【？原文待核】、椒目各一升，芒硝六两，水银十两，水煮水银三日三夜，乃以捣的六万杵，自相合丸，服如大豆丸，日三服，日增一丸，至十丸更从一起。先煮水银三日三夜，是减轻水银毒性，捣的六万杵，是要求粒子细，接触面大。方中姚同不知是何物？但起主要作用的是水银，其他药物都是次要，欧洲是1924年时才制出利尿剂撒利汞（Mersalyl）。汞利尿，比胡洽居士水银丸要晚1300多年，故历史上利尿剂利尿作用最早的是我国五世纪时的胡洽，这是我们的光荣。

（原书第13–14页）

## 六、银膏——最早的汞合金补牙

用汞合金充填牙齿，也是以我国为最早。远在659年时，唐代《新本草》中，即有了记载。

> "以白锡合银及水银合成之，亦堪补牙齿缺落。又当凝硬如银，合炼有法。"

在公元1518一1593年的李时珍《本草纲目》中，也有了记载，并云今方士家有银膏，悉即此物。远在1300年前，我国即应用银锡配制的汞合金修复病牙，说明了我国不仅化学和冶金学很发达，同时还证明当时牙科修复学方面也有了相当的成就。欧洲是在1819年美国的Bell和1926年德国的N. Taveall氏才开始使用这一方法，而且其制法还很原始，对比起来时间比我国晚得多。

（原书第14页）

## 本章要点

1. 本章辑录《周礼·天官冢宰篇》疡医"五毒"之药及郑玄（康成）注，是为中国古代文献中最早的丹药（化学制剂）记载之一。
2. "五毒"即石胆（硫酸铜）、丹砂（硫化汞）、雄黄（硫化砷）、礜石（砷黄铁矿）、慈石（四氧化三铁），合置"黄堥"（陶制丹罐，即后世阳城罐）中烧三日三夜、升华成一种具腐蚀性的丹药。
3. 作者张觉人认为该"五毒"之药近似后世的白降丹或红升丹（氧化汞类），并从"恶肉败骨则尽出"的记载推断其为腐蚀性丹药。
4. 胡洽《百病方》所载水银丸被作者视为我国乃至世界上最早的汞利尿剂，早于欧洲撒利汞（Mersalyl）一千三百余年。
5. 唐代《新本草》及李时珍《本草纲目》所载"银膏"（银锡水银汞合金），是我国应用汞合金修复牙齿的最早记录，远早于欧美。
6. 本章主旨在于借《周礼》、胡洽水银丸、唐代银膏等文献，论证我国炼丹术及化学、医药应用（丹药、利尿剂、牙科材料）在历史上的领先地位。
